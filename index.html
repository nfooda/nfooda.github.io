About

I'm a Ph.D. student at the University of Maryland, advised by Prof. Dave Levin. I work on Internet measurement and network security, with a focus on the Web PKI: how quickly certificate revocations actually reach browsers, how Firefox checks revocation at scale with CRLite, and how privacy technologies like DNS over HTTPS and Encrypted Client Hello are used in practice. My work has appeared at ACM SIGCOMM and ACM IMC.

Research

How fast do certificate revocations reach browsers?

When a website's certificate is revoked, browsers can keep trusting it for hours or days. I built a framework that issues and immediately revokes certificates, then watches each certificate authority's OCSP, CRL, and CRLite data until the revocation appears, measuring that window of vulnerability across the CAs behind most of the web. I'm now extending it to the long tail of CAs.

Revocation checking at scale with CRLite

With Mozilla, I evaluated CRLite, the system that lets every Firefox desktop user check certificate revocation privately and locally. Using real Firefox telemetry, we measured how much of the web it covers, where it falls short, and how it holds up during mass-revocation events.

Measuring web privacy from the user's side

I'm building a privacy-preserving Firefox extension that measures how often real users' connections actually use encrypted DNS, Encrypted Client Hello, and modern revocation checking, ahead of a user study with about 200 participants.
